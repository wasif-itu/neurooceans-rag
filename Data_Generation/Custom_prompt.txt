Comprehensive Prompt for Generating LifeWeaver Persona Data
Purpose
Generate complete LifeWeaver chat data for specified famous personalities, with realistic conversations spanning their entire lives across multiple chat threads (WhatsApp and iMessage), plus a separate text file of search engine queries for images. This data will seed a story-generation application that creates narratives from chat history.
System Context
Application: LifeWeaver - An AI story generation system that takes thousands of pictures, WhatsApp messages, and iMessages to create life stories (daily, weekly, monthly, yearly summaries) for individuals.
Data Requirements:
Chat Messages: Multiple chat threads (3-10 per person) with 10-50 messages each, spanning different life phases, in JSON format
Image Search Queries: 10 search engine queries in a separate .txt file that would retrieve relevant images from different moments in the person's life
Persona Generation Rules
1. Persona Selection
You will be given the name of a famous person. You must generate data for that specific person only. Do not select or suggest alternative personas.
2. Persona Context Structure
For the given persona, define:
Name: Full name
Birth Year: Year of birth
Nationality: Country of origin
Hometown: City/region
Brief Description: 1-2 sentences summarizing their significance
Key Relationships: 3-10 important people in their life (family, friends, colleagues, rivals) - include realistic names
Personality Traits: How they speak, text, behave (e.g., "Warm, sarcastic, uses lowercase, lots of emojis")
Life Arc: Major events from childhood to present day
3. Chat Thread Generation
Thread Requirements:
3-10 threads per person (mix of WhatsApp and iMessage)
10-50 messages per thread
Cover different life phases (childhood, career start, peak, late career, post-career)
Each thread has a unique contact/relationship
Natural chronological flow with gaps (hours, days, weeks, sometimes years)
Chat Types (choose 3-8):
Mentor/Manager/Coach: Career guidance, professional relationship
Parent/Close Family: Personal life, support, family matters
Best Friend/Confidante: Deep conversations, emotional support
Romantic Partner/Spouse: Love, relationship milestones, family
Rival/Peer: Competition, mutual respect, friendly banter
Child: Fatherhood/motherhood, legacy, teaching
Teammate/Colleague: Professional collaboration, shared success
Family Group Chat: Extended family, celebrations, connectedness
Message Attributes:
date: "YYYY-MM-DD" format, any real past date
hour: 0-23 integer
minute: 0-59 integer
is_from_me: boolean (true = persona, false = contact)
content: message text (plain, no markdown, no HTML)
4. Writing Style Rules
Realistic Texting Voice:
Casual, natural texting: lowercase, occasional typos, emojis
Contractions (can't, don't, won't, gonna, wanna)
Sentence fragments, ellipses for trailing off
No formal/narrated prose - read like actual text messages
Character Consistency:
Each persona has a distinct voice matching their personality
Each contact has a consistent voice
Use real events, dates, feelings, callbacks to earlier messages
Avoid generic filler ("that's great!", "how are you") - every exchange must carry real detail
Chronological Flow:
Spread across realistic dates and times
Natural gaps (hours, days, sometimes weeks) between exchanges
Story arc within each thread (beginning → middle → emotional peak → resolution)
Content Specificity:
Name real events, dates, feelings, callbacks
Concrete details that can later be retrieved and quoted by story-generation model
Avoid PII (phone numbers, addresses, etc.)
5. Search Engine Queries Generation
Format: Separate .txt file with 10 search queries, one per line
Coverage: Queries should span the persona's entire life arc:
Childhood/hometown
Early career breakthrough
Peak success moments
Personal milestones (weddings, children)
Later career/post-career
Legacy moments
Controversies or challenges
Awards/recognition
Query Format: Plain text search queries that would retrieve relevant images
Use specific keywords (names, dates, events, locations)
Include relevant descriptors (e.g., "celebrating", "training", "with family")
Search engine optimized format
Examples:
text
Lewis Hamilton Stevenage childhood go-karting 1990sLewis Hamilton first win World Championship 2008 McLarenLewis Hamilton record 7th World Championship 2020 Turkey

Quality Control Checklist
Per Persona:
□ 3-10 unique chat threads created
□ 10-50 messages per thread (mix of lengths)
□ 10 search queries in separate .txt file covering different life moments
□ Multiple life phases covered (childhood → peak → present)
□ Consistent character voice throughout
□ Realistic conversations with emotional arc
□ Chronological ordering with natural gaps
□ No PII (phone numbers, addresses)
□ Specific details/events that can be retrieved later
□ Proper JSON formatting (valid, no trailing commas)
Overall:
□ All messages in plain text (no markdown, no HTML)
□ Mix of WhatsApp and iMessage threads
□ Natural alternation of is_from_me (not 1-for-1 pattern)
□ Realistic dates (historical/current, not all same day)
□ Queries.txt file has exactly 10 queries, one per line
Advanced Tips
For Maximum Realism:
Reference pop culture and current events of the time period
Use era-appropriate slang (e.g., "lol" appears in 2000s+, "haha" across all eras)
Include inside jokes and callbacks to earlier messages
Vary message lengths (short texts, longer emotional messages)
Add typos occasionally but not too many (realistic but not sloppy)
Include group chats for family and friends (adds social dimension)
Thread story arcs that span weeks/months within each chat
For Story Generation Quality:
Seed emotional moments that can be expanded into full stories
Include specific dates and times for event anchoring
Use concrete language ("the 2019 Mexico race" vs "that race")
Name key people and places for contextual richness
Include contrasting viewpoints (argument, disagreement, resolution)
For Search Queries:
Cover different eras of the person's life
Include key milestones that would have generated significant media coverage
Use specific keywords (names, dates, events, locations)
Format as actual search queries that would retrieve relevant images
Include 10 distinct moments - no repeats
